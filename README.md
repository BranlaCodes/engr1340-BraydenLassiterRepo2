# ENGR 1340 Assignment 4 - Repo 2

**Student:** Brayden Lassiter

This public repository demonstrates collaborator-based and fork-based GitHub workflows for ENGR 1340 Assignment 4. Teammates will contribute from branches inside this repository and through a separate fork-based pull request.

## Files

- `subtraction.md` explains subtraction and provides accurate examples.
- A collaborator will add `multiplication.md` or `division.md` from their assigned teammate-named branch.

## Required collaborator workflow

Each teammate should accept the collaborator invitation, work only in the branch named for them, add either `multiplication.md` or `division.md`, and open a pull request from that branch into `main`.

## Required fork workflow

A teammate should separately fork this repository, make a small legitimate improvement in the fork, and open a pull request from the fork into this repository's `main` branch.
